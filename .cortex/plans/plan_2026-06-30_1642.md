## Implementation Steps

### Phase 1: Python Backend — Dependencies & Geospatial Engine

**Step 1.1** — Add Python dependencies to root `pyproject.toml`:
```
shapely = "^2.0"
fiona = "^1.10"
geoarrow-pyarrow = "^0.1"
```
(shapely 2.0+ bundles GEOS; fiona bundles GDAL wheels on most platforms)

**Step 1.2** — Add geospatial file type support to `input_schema.py`:
- Create `InputShapefileTable(InputTableBase)` with `file_type: Literal["shapefile"] = "shapefile"`
- Create `InputGeoParquetTable(InputTableBase)` with `file_type: Literal["geoparquet"] = "geoparquet"`
- Create `InputGeoJsonTable(InputTableBase)` with `file_type: Literal["geojson"] = "geojson"` and optional `geometry_column: str = "geometry"`
- Extend `InputTableSettings` discriminated union with the three new types
- Extend `ReceivedTable.file_type` Literal to include `"shapefile" | "geoparquet" | "geojson"`
- Create `NodeSpatialRead(NodeBase)` with `received_file: ReceivedTable`
- Create `NodeSpatialJoin(NodeMultiInput)` with `join_predicate: Literal["intersects", "contains", "within"] = "intersects"`, `left_geom_col`, `right_geom_col`
- Create `NodeBufferGeometry(NodeSingleInput)` with `geom_col: str = "_flowfile_geom"`, `distance: float = 0.001`, `resolution: int = 16`

**Step 1.3** — Add `NodeTag` entries in `schemas.py`:
```python
SHAPEFILE = "shapefile"
GEOJSON = "geojson"
GEOPARQUET = "geoparquet"
SPATIAL = "spatial"
GEOMETRY = "geometry"
GIS = "gis"
BUFFER = "buffer"
```

**Step 1.4** — Register new node templates in `configs/node_store/nodes.py`:
- `NodeTemplate(item="spatial_read", input=0, output=1, node_type="input", node_group="input", laziness="eager", tags=[SHAPEFILE, GEOJSON, GEOPARQUET, SPATIAL, GIS, READ, FILE])`
- `NodeTemplate(item="spatial_join", input=2, output=1, node_type="process", node_group="combine", laziness="eager", tags=[SPATIAL, JOIN, GIS, GEOMETRY])`
- `NodeTemplate(item="buffer_geometry", input=1, output=1, node_type="process", node_group="transform", laziness="eager", tags=[SPATIAL, BUFFER, GIS, GEOMETRY])`

**Step 1.5** — Add to `NODE_TYPE_TO_SETTINGS_CLASS` in `schemas.py`:
```python
"spatial_read": input_schema.NodeSpatialRead,
"spatial_join": input_schema.NodeSpatialJoin,
"buffer_geometry": input_schema.NodeBufferGeometry,
```

**Step 1.6** — Create `flowfile_core/flowfile_core/flowfile/flow_data_engine/create/geo_funcs.py`:
- `create_from_path_shapefile(received_table)` — uses fiona to read .shp, converts geometry to WKB binary column `_flowfile_geom`, attributes to Polars DataFrame
- `create_from_path_geoparquet(received_table)` — reads via `pl.scan_parquet` + geoarrow metadata detection
- `create_from_path_geojson(received_table)` — parses GeoJSON features, extracts properties → Polars, geometry → WKB column

**Step 1.7** — Add handlers to `file_type_handlers` dict in `flow_data_engine.py:1268`:
```python
"shapefile": geo_funcs.create_from_path_shapefile,
"geoparquet": geo_funcs.create_from_path_geoparquet,
"geojson": geo_funcs.create_from_path_geojson,
```

**Step 1.8** — Add `add_spatial_read()`, `add_spatial_join()`, `add_buffer_geometry()` methods to `flow_graph.py`:
- `add_spatial_read`: similar to `add_read` but always eager (geospatial ops not lazy-compatible)
- `add_spatial_join`: collects both inputs, uses `shapely.STRtree` for indexed predicate join, returns merged Polars DataFrame
- `add_buffer_geometry`: applies `shapely.buffer()` to each geometry in the specified column

**Step 1.9** — Mirror in worker (`flowfile_worker/create/`):
- Add to `FileType` Literal
- Add `create_from_path_shapefile/geoparquet/geojson` to worker's `funcs.py`
- Add cases to `table_creator_factory_method()`

### Phase 2: Spatial Preview API Endpoint

**Step 2.1** — Create `flowfile_core/flowfile_core/routes/spatial_preview.py`:
- `GET /node/spatial_preview?flow_id=&node_id=&geom_col=&max_polygons=5000&tolerance=0.001`
- Implements the downsampling/simplification engine from the spec:
  - Fetches node output DataFrame (max 5000 rows via uniform sampling)
  - Deserializes WKB geometries via shapely
  - Validates and simplifies (Douglas-Peucker)
