## Context

The current geospatial implementation uses **shapely** (for geometry operations: WKB parsing, STRtree, buffer, simplify) and **fiona** (for Shapefile reading). The user wants to replace both with **DuckDB Spatial**, which:

- Reads Shapefiles, GeoJSON, and GeoParquet natively via SQL (`ST_Read`)
- Performs spatial joins via SQL (`ST_Intersects`, `ST_Contains`, `ST_Within`)
- Buffers geometries via SQL (`ST_Buffer`)
- Converts to GeoJSON for preview via SQL (`ST_AsGeoJSON`, `ST_SimplifyPreserveTopology`)
- Operates directly on Polars DataFrames via Apache Arrow zero-copy (`con.execute("SELECT ... FROM df").arrow()` → `pl.from_arrow()`)
- Eliminates the need for GEOS/GDAL/PROJ system libraries in Docker and PyInstaller bundles

**Files that currently use shapely/fiona (all must change):**
1. `flowfile_core/flowfile_core/flowfile/flow_data_engine/create/geo_funcs.py` — readers
2. `flowfile_worker/flowfile_worker/create/geo_funcs.py` — worker readers (mirror)
3. `flowfile_core/flowfile_core/flowfile/flow_graph.py:4551-4650` — spatial_join + buffer_geometry methods
4. `flowfile_core/flowfile_core/routes/spatial_preview.py` — WKB→GeoJSON conversion
5. `flowfile_core/flowfile_core/flowfile/flow_node/flow_node.py:48-62` — `_sanitize_example_data` WKB→WKT
6. `pyproject.toml` — replace shapely/fiona/geoarrow-pyarrow with duckdb
7. `build_backends/build_backends/main.py` — replace shapely/fiona bundling with duckdb
8. `flowfile_core/Dockerfile` — remove libgdal/libgeos/libproj (no longer needed)
9. `flowfile_worker/Dockerfile` — remove libgdal/libgeos/libproj

### Step 2: Rewrite `flowfile_core/.../create/geo_funcs.py`
Replace shapely/fiona logic with DuckDB Spatial:

```python
import json
import polars as pl
import duckdb
from flowfile_core.schemas import input_schema

GEOM_COL = "_flowfile_geom"

def _get_spatial_con():
    con = duckdb.connect()
    con.execute("INSTALL spatial; LOAD spatial;")
    return con

def create_from_path_shapefile(received_table):
    con = _get_spatial_con()
    arrow = con.execute(f"""
        SELECT * REPLACE (ST_AsWKB(geom) AS geom)
        FROM ST_Read('{received_table.abs_file_path}')
    """).arrow()
    df = pl.from_arrow(arrow)
    # Rename DuckDB's default 'geom' column to our convention
    if "geom" in df.columns:
        df = df.rename({"geom": GEOM_COL})
    return df

def create_from_path_geoparquet(received_table):
    con = _get_spatial_con()
    arrow = con.execute(f"""
        SELECT * REPLACE (ST_AsWKB(geometry) AS geometry)
        FROM '{received_table.abs_file_path}'
    """).arrow()
    df = pl.from_arrow(arrow)
    # Detect and rename geometry column
    for col in ("geometry", "geom"):
        if col in df.columns:
            df = df.rename({col: GEOM_COL})
            break
    return df

def create_from_path_geojson(received_table):
    con = _get_spatial_con()
    arrow = con.execute(f"""
        SELECT * REPLACE (ST_AsWKB(geom) AS geom)
        FROM ST_Read('{received_table.abs_file_path}')
    """).arrow()
    df = pl.from_arrow(arrow)
    if "geom" in df.columns:
        df = df.rename({"geom": GEOM_COL})
    return df
```

### Step 4: Rewrite `add_spatial_join` in `flow_graph.py`
Replace STRtree with DuckDB SQL spatial join:
```python
def _func(left_engine, right_engine):
    left_df = left_engine.collect()
    right_df = right_engine.collect()
    con = duckdb.connect()
    con.execute("LOAD spatial;")
    
    predicate_sql = {
        "intersects": "ST_Intersects",
        "contains": "ST_Contains",
        "within": "ST_Within",
    }[input_file.join_predicate]
    
    # DuckDB reads both Polars DataFrames directly via Arrow
    arrow = con.execute(f"""
        SELECT l.*, r.* EXCLUDE ({right_col})
        FROM left_df l, right_df r
        WHERE {predicate_sql}(
            ST_GeomFromWKB(l.{left_col}),
            ST_GeomFromWKB(r.{right_col})
        )
    """).arrow()
    result = pl.from_arrow(arrow)
    return FlowDataEngine(result)
```
